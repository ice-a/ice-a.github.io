复制即诊断，工具随手可用。

fde-clip 是轻量级、全平台的离线剪贴板工具箱。自动嗅探你复制的内容并本地诊断风险，内置 15 个常用编解码与格式化工具，可选接入完整 CyberChef 操作库。无账号、无网络请求、无 AI。

核心功能

剪贴板历史 + 诊断

后台监听文本，本地 SQLite 保存；全文 / 正则搜索、置顶、自动过期。复制后 200ms 内检测密钥泄露、JSON 语法、危险命令、可疑 URL、编码乱码等，高危内容非侵入提示并可一键打码。

15 个常用工具

JSON ↔ YAML、时间戳 ↔ 日期、Cron 解析、Base64 文本与图片编解码、JSON / SQL 格式化、SHA-256、密码生成、UUID、WebP 图片压缩。配方可拖拽排序并导出 JSON。

纯粹与隐私

所有内容只留在本机，不上传、不联网、不需要账号。桌面端托盘常驻、关闭窗口后台运行、可选开机自启；Android 后台监听必须由用户主动授权无障碍服务。
